# PigPower SmartFarm Platform

An enterprise Agri-Tech platform designed to digitally transform Lesotho's pork value chain through farmer aggregation, livestock traceability, renewable energy integration, and data-driven decision-making.

## Project Structure

```
PigPower-SmartFarm-Platform/
├── mobile/       # Flutter mobile application
├── backend/      # FastAPI backend
├── docs/         # Software documentation
├── database/     # Database scripts and migrations
├── assets/       # Images and shared resources
└── .github/      # GitHub workflows
```

## Technology Stack

### Mobile

- Flutter
- Dart

### Backend

- Python
- FastAPI

### Database

- PostgreSQL
